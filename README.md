# 🎓 Alumni Network Platform

## Project Overview

The Alumni Network Platform is a web-based application developed to connect students and alumni of a university. The platform helps students explore job opportunities, participate in alumni events, interact with alumni, and receive career guidance. It also provides an Admin Dashboard to manage users, jobs, events, applications, and feedback.

## Installation

1. Install Node.js.
2. Install MongoDB.
3. Open the project in VS Code.
4. Open the backend folder.
5. Install dependencies using:

npm install

6. Start the backend server:

npm run dev

7. Open the frontend using Live Server.
